# Guia de Contribuição — SpectraViewer

Agradecemos o interesse em contribuir com o **SpectraViewer**!

---

## 1. Como Contribuir
- Instale dependências com `make install` ou `pip install -r requirements.txt`.
- Execute a aplicação localmente com `make run`.
- Commits no padrão convencional (`feat:`, `fix:`, `docs:`).
